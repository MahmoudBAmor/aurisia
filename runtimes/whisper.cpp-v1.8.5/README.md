# whisper.cpp 1.8.5 Windows x64 runtime

The runtime binaries are installed from the official CPU-only
`whisper-bin-x64.zip` release asset by `tools/install-whisper.ps1`.
`whisper-server.exe` is the configured persistent ASR runtime;
`whisper-cli.exe` remains available for diagnostics. Executables and DLLs are
excluded from Git; this README records the reproducible runtime location
expected by `config/aurisia.yaml`.
