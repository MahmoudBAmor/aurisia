# Changelog

All notable changes to Aurisia will be documented in this file. The format is
based on Keep a Changelog, and the project uses semantic versioning once a
public release is tagged.

## Unreleased

### Planned

- Google Play-compatible model delivery and release signing.
- Broader consented evaluation across speakers, devices, and acoustic spaces.
- Further formal-Arabic and session-local speaker-attribution evaluation.

## 0.1.0-beta - 2026-09-07

### Added

- Offline Android transcription for Tunisian Arabic and formal Arabic.
- Arabic-script display with conservative Tunisian/French normalization.
- Streaming partial text, guarded final refinement, and automatic scrolling.
- Session-local speaker colouring and a high-contrast senior-friendly theme.
- Replaceable ports for audio, VAD, ASR, speaker attribution, and presentation.
- Windows desktop proof of concept and model-neutral evaluation tooling.

### Security

- Checksum-pinned model installers and ignored local speech data.
- Public-repository audit and privacy documentation.
